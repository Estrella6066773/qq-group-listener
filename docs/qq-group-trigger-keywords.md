# QQ 群触发关键词表（成瘾品，酒除外）

> 用途：QQ 群「关键词触发」规则的匹配词库。**本表不投放至群聊**。
> 版本：v1.0 ｜ 2026-09-22 ｜ 维护：艾丽卡

## 一、匹配原则

1. **范围**：一切成瘾性物质，**排除酒精类**（酒、啤酒、白酒、红酒、鸡尾酒等一律不触发）。
2. **大小写/繁简**：匹配时应做**大小写不敏感**与**简繁归一**（如 檳榔=槟榔）。
3. **子串匹配**：中文按子串匹配（"嚼槟榔" 命中 "槟榔"）；英文按词边界匹配，避免误伤（如 "ice" 不匹配 "nice"）。
4. **误伤控制**：对易混淆词（如"烟"）建议用复合词（"抽烟/吸烟/香烟/烟瘾"），避免命中"烟囱""烟雾报警"等。
5. **同义/黑话**：毒品类大量使用代称，必须一并收录，否则形同虚设。
